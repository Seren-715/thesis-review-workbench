# SVN论文检查智能体：P001小批次实验阶段报告

日期：2026-10-07。状态：单学生原型链路已跑通，老师的整体任务尚未完成。

## 目标与实现

验证“教师历史论文导出 → 批注与原文证据提取 → 候选检查项 → 有限规则 → 学生初稿检查 → 智能体报告和用量记录”的最小链路。

基于固定提交的 nanobot 源码（b0d28af321933dbae08aa02a4d5d2a75fbbda9f0，nanobot-ai 0.3.5），新增项目工具并复用 Tool、tool_parameters、ToolRegistry；模型请求、权限检查和停止机制由独立任务循环控制。没有修改或部署 nanobot 默认 AgentRunner，也没有依赖通用编码智能体 SDK 作为运行服务。最终程序直接调用 DeepSeek API。

## 数据和证据

- SVN快照：r502；论文学生：P001；教师提交者字段：mayy。SVN提交者与DOCX批注作者分别保存，不相互替代。
- 教师论文导出：r300、r247，共2份；保留版本、原路径、时间、原文件字节数和SHA-256。
- 提取18条批注：14条有文字、4条空文字；18条完整锚点；2个含公式的选区、3个OMML附件、1张批注图片。空批注不猜测含义。
- 3条选定批注生成5项候选，只覆盖指定子问题；未经语义核验的模型候选不直接全量启用。
- 试验规则：R001结论中的“我”字线索；R002公式编号文本。两个编号候选合为同一规则族；字体与删除对象保留待核验。
- r194由学生账号huangfp新增论文，提交说明“初稿”，无复制来源，早于教师首改r206。这里只确认保存日志中的初稿身份，不证明不存在更早线下稿。

6000 token是已知累计用量的软停止阈值，单次请求可能越过阈值；10000字节是序列化请求规模限制，不是token数。当前没有实现严格的任务总token预算。异常或缺少usage时成本记为未知，不记成零。

## 验证和下一阶段

本地验证覆盖来源哈希、批注引文、目录和结论边界、普通引用与编号区分、图片标签覆盖、空公式及错误参数等边界；模拟模型测试包含批量/顺序调用、失败与用量审计。真实API结果另外核对，与模拟测试区分保存。

下一阶段增加两名学生，每人最多两份教师论文，仍保持小批次：先导出和提取证据，不调用模型；核对有文字批注与作者身份后，继续自动分类、按独立学生归纳同类问题。一个学生多版本、同一学生多个编号批注不计成独立的常见性证据。

尚未完成：全部批注归纳、跨学生常见性验证、全部学生初稿检查、旧DOC/OLE和更多公式格式支持、独立测试与误报漏报评价、视觉问题处理、统一自主调度及严格总预算控制。
